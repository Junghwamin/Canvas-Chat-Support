# 법적 문서

이 폴더는 Canvas-Chat 공개 지원 저장소에서 유지할 법적 문서의 공개본을 담습니다.

- [legacy-mit.txt](legacy-mit.txt): 2026-10-13 라이선스 전환 전 MIT로 제공된 자료의 권리와 고지를 보존하는 원문입니다.
- [policies/](policies/): 서비스 화면에 표시되는 공개 고지를 Markdown/JSON 문서로 옮긴 공개본입니다. 앱 소스의 TypeScript 파일은 게시하지 않습니다.

현재 앱 소스는 비공개 저장소에서 관리합니다. 공개 저장소에는 법적 고지 원문, 변경 기록, 공개 가능한 미디어 출처만 둡니다.
