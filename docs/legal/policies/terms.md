# 이용약관

Canvas-Chat은 무료로 운영하는 비상업 개인 프로젝트입니다. 내 API 키로 쓰고, 데이터는 내 브라우저에 남습니다. 이 약관은 그 방식에서 생기는 책임을 정합니다.

> 운영자가 작성했습니다. 전문 법률 검토는 받지 않았습니다.

시행일: 2026년 10월 14일 · 최종 수정: 2026년 10월 14일

## 서비스

Canvas-Chat은 질문을 캔버스에 펼치고, 문서에 묻고, 학습 노트로 정리하는 웹 앱입니다. 가입 없이 쓰며, 앱은 이용자의 브라우저 안에서 동작합니다.

AI 기능은 이용자가 넣은 API 키로 AI 제공자를 부릅니다. 대화는 이용자가 고른 제공자(OpenAI, Google, 내 컴퓨터의 Ollama)로, 문서 색인은 설정에서 고른 OpenAI나 Google로, 이미지 만들기 같은 일부 기능은 OpenAI로 갑니다. 운영자의 서버는 웹 검색, URL 가져오기, 링크 미리보기만 전달합니다.

개인정보를 어떻게 다루는지는 개인정보 처리방침(/privacy)에, AI가 만드는 것과 그 표시는 AI 이용 안내(/ai-notice)에 있습니다.

## API 키와 비용은 이용자 책임

- API 키를 만들고 관리하고 지키는 일은 이용자가 합니다. 각 제공자의 약관과 이용 정책을 따라야 합니다.
- AI 요청 요금은 키를 만든 이용자의 제공자 계정에 청구됩니다. 운영자는 요금을 대신 내거나 돌려주지 않습니다. 사용량 한도는 제공자 콘솔에서 직접 정해 두세요.
- 키가 새어 나갔다고 생각되면 제공자 콘솔에서 바로 폐기하고 새 키를 만드세요.
- 다른 사람의 키를 허락 없이 쓰면 안 됩니다.

## 데이터와 백업

데이터는 이용자의 브라우저에만 저장되고 운영자에게는 사본이 없습니다. 브라우저 데이터 삭제, 기기 고장, 브라우저의 저장 공간 정리로 데이터가 사라질 수 있으며 운영자는 이를 되살릴 수 없습니다. 중요한 내용은 데이터 백업 화면에서 정기적으로 백업하세요.

## AI가 만든 결과

- AI가 만든 답, 요약, 카드, 이미지는 틀리거나 오래되었거나 한쪽으로 치우칠 수 있습니다. 운영자는 정확성이나 특정 목적에 맞는지를 보증하지 않습니다.
- AI의 답은 의료, 법률, 금융 같은 전문가의 조언을 대신하지 않습니다. 중요한 내용은 원문이나 전문가에게 확인하세요.
- 결과를 어떻게 쓸지는 이용자가 정하고, 그 책임도 이용자에게 있습니다.
- 내보낸 파일에 붙는 ‘AI 생성 콘텐츠 포함’ 표시는 지우지 말아 주세요. 다른 곳에 올릴 때도 AI가 만든 내용임을 밝혀 주세요.

## 하면 안 되는 일

- 법을 어기는 콘텐츠를 만들거나 퍼뜨리는 일
- 다른 사람의 저작권, 개인정보, 명예 같은 권리를 침해하는 일
- URL 가져오기나 웹 검색 기능을 대량으로 자동 호출하거나, 다른 시스템을 탐색하고 공격하는 데 쓰는 일
- 요청 제한이나 보안 장치를 피하거나 서비스 운영을 방해하는 일
- AI 제공자의 이용 정책이 금지하는 용도로 쓰는 일

이런 이용이 확인되면 운영자는 해당 요청을 막을 수 있습니다.

## 서비스가 멈출 수 있는 경우

이 서비스는 호스팅 업체(Vercel)의 무료 요금제 한도 안에서 운영합니다. 전송량이나 서버 실행 횟수 같은 무료 사용량 한도에 닿으면 Vercel 정책에 따라 최대 30일 동안 서비스가 멈출 수 있습니다. 운영자는 미리 알리지 않고 기능을 바꾸거나 서비스를 끝낼 수 있습니다.

서비스가 멈춰도 브라우저에 저장된 데이터는 지워지지 않지만, 다시 열릴 때까지 앱 화면을 쓸 수 없습니다. 백업 파일을 받아 두면 다른 주소에서 복원할 수 있습니다.

## 보증하지 않는 것과 책임의 한계

서비스는 ‘있는 그대로’ 제공합니다. 운영자는 서비스가 끊기지 않거나 오류가 없다고 보증하지 않습니다.

운영자의 고의나 중대한 과실이 없다면, 관련 법이 허용하는 범위에서 무료 서비스 이용으로 생긴 손해(데이터 손실, 제공자 요금, AI 결과를 믿고 한 일 등)에 책임지지 않습니다.

## 저작권과 라이선스

이용자가 만든 내용의 권리는 이용자에게 있습니다. Canvas-Chat 자체 코드와 문서에는 PolyForm Noncommercial License 1.0.0을 적용합니다. 소스 저장소는 비공개로 관리하며, 이 라이선스의 허용 범위를 벗어나는 상업적 이용에는 권리자의 사전 서면 허락 또는 별도 상업용 라이선스 계약이 필요합니다. 문의는 지원 저장소의 GitHub Issues(https://github.com/Junghwamin/Canvas-Chat-Support/issues)로 보내 주세요. 사진, 영상, 글꼴의 출처와 라이선스는 ‘사진과 영상 출처’ 화면(/credits)에 있습니다.
