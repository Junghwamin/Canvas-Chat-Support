# AI 이용 안내

Canvas-Chat은 생성형 AI를 쓰는 서비스입니다. 무엇을 AI가 만드는지, 내 질문이 어디로 가는지, AI가 만든 내용을 어떻게 표시하는지 미리 알려 드립니다.

> 운영자가 작성했습니다. 전문 법률 검토는 받지 않았습니다.

시행일: 2026년 10월 14일 · 최종 수정: 2026년 10월 14일

## AI가 만드는 것

이용자가 요청할 때만 생성형 AI가 아래 결과를 만듭니다.

- 캔버스와 학습 노트의 답변, 요약, 제목
- 노트에서 고른 글을 AI로 고쳐 쓴 결과(인라인 AI)
- 플래시카드와 퀴즈
- 문서 질문의 답과 추천 질문
- 이미지 만들기로 만든 그림
- 오디오 요약의 대본과 읽어 주는 음성
- 음성 입력을 OpenAI로 받아 적은 글

이용자가 직접 쓴 글, 올린 문서의 원문, 검색 결과의 원문은 AI가 만든 것이 아닙니다. 캔버스에서는 AI 답 카드에 그 답을 만든 모델 이름이 함께 보입니다.

## 내 질문은 어디로 가나요

질문, 이어지는 대화 내용, 첨부한 내용, 답에 쓰려고 고른 문서 조각은 이 브라우저에서 이용자가 고른 제공자(OpenAI, Google, 내 컴퓨터의 Ollama)로 바로 갑니다. 문서 색인(문서로 넣은 글 전체)과 문서 질문의 검색은 설정의 ‘문서 색인 모델’이 정한 OpenAI나 Google로 갑니다. 이미지 만들기, OpenAI 받아쓰기, 오디오 요약의 읽어 주는 음성은 OpenAI 키를 넣어 두었으면 고른 제공자와 상관없이 OpenAI로 갑니다. 운영자의 서버는 이 내용을 받거나 저장하지 않습니다. 다만 웹 검색을 켜면 질문 글(앞 400자까지)이 운영자의 서버를 거쳐 Tavily·Brave로 갑니다(저장하지 않음). 자세한 내용은 개인정보 처리방침에 있습니다.

## 처음 한 번 뜨는 안내

앱에서 AI에게 처음 요청하기 전에 ‘AI 사용 안내’ 창이 뜹니다. [확인하고 계속]을 눌러야 요청을 보내고, [취소]를 누르면 아무것도 보내지 않습니다. 창에는 아래 세 문장이 나옵니다.

- 답변·요약·제목 같은 결과는 생성형 AI(OpenAI·Google Gemini·내 PC의 Ollama)가 만듭니다. 틀리거나 오래된 내용이 있을 수 있으니 중요한 내용은 직접 확인하세요.
- 질문, 첨부한 내용, 대화 맥락은 이 브라우저에서 내가 고른 AI 제공자에게 직접 보내집니다(해외 서버일 수 있습니다). 이 앱의 서버는 대화를 저장하지 않습니다.
- API 키와 작업 데이터는 이 브라우저에만 저장됩니다. 웹 검색을 켜면 검색어가 이 앱의 검색 중계를 거쳐 Tavily·Brave로 갑니다.

확인한 기록은 이 브라우저(localStorage)에만 남습니다. 브라우저 데이터를 지우거나 다른 브라우저에서 열면 다시 안내합니다. 안내 내용이 크게 바뀌면 다시 묻습니다.

## 내보낸 파일의 AI 표시

AI가 만든 내용이 들어 있는 캔버스와 학습 노트를 내보내면 아래처럼 그 사실을 적습니다.

- 캔버스 Markdown: 파일 머리말(front-matter)에 ai_generated: true와 ‘AI 생성 콘텐츠 포함’, 만든 모델, 생성일을 적습니다.
- 캔버스 JSON: 파일 안 export 항목에 같은 표시와 모델, 생성일을 적습니다.
- 캔버스 Word(DOCX): 문서 제목 아래에 ‘AI 생성 콘텐츠 포함’과 모델, 생성일을 적습니다.
- 캔버스 인쇄와 PDF: 머리말과 쪽마다 바닥글에 ‘AI 생성 콘텐츠 포함’과 모델, 생성일을 적습니다.
- 학습 노트 인쇄와 PDF: AI 답 카드가 들어 있으면 머리말과 쪽마다 바닥글에 ‘AI 생성 콘텐츠 포함’을 적습니다. 화면 캡처(PNG, 이미지 PDF)에도 AI 답 카드가 있으면 그림 아래에 같은 표시를 붙입니다.
- AI 답의 차트 PNG와 문서 질문의 통계 차트 그림(PNG, JPEG): 그림 아래에 ‘AI 생성 콘텐츠 포함’을 적습니다. 직접 쓴 글에서 만든 차트에는 붙이지 않습니다.
- 이미지 만들기로 새로 만든 PNG 그림: 파일 안 설명에도 ‘AI 생성 콘텐츠 포함’을 적습니다. 이 표시에는 질문, 만든 모델, 키를 넣지 않습니다. 캔버스의 ‘생성한 이미지’ 답 카드에는 만든 모델 이름도 보입니다.

학습 노트의 JSON, 답 속 표·차트의 CSV, 문서 질문의 통계를 저장한 Excel·CSV에는 아직 이 표시가 없습니다. 예전에 만든 그림에는 파일 안 표시가 없을 수 있습니다. 그런 파일이나 그림을 다른 곳에 올릴 때는 AI가 만든 내용임을 직접 밝혀 주세요. 위의 표시는 지우지 말아 주세요.

## 믿기 전에 확인하세요

- AI의 답은 그럴듯해 보여도 틀릴 수 있습니다. 문서 질문의 답에 붙은 [1] 같은 번호를 눌러 원문을 확인하세요.
- 의료, 법률, 금융처럼 중요한 결정에는 AI의 답만으로 판단하지 마세요.
- 부적절하거나 해로운 결과를 보았다면 GitHub Issues로 알려 주세요. 각 AI 제공자에게 직접 신고할 수도 있습니다.

## 이 안내를 하는 이유

「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제31조(인공지능 투명성 확보 의무)는 생성형 AI를 쓰는 서비스임을 미리 알리고 AI가 만든 결과임을 표시하도록 정합니다. 이 화면과 앱의 첫 안내, 내보낸 파일의 표시는 그 취지에 맞추려는 것입니다.
