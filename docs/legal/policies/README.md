# 공개 법적 고지

이 폴더는 Canvas-Chat 서비스의 공개 법적 고지를 Markdown과 JSON으로 관리합니다. 앱 화면의 TypeScript 소스는 게시하지 않고, 공개해야 하는 문서 내용만 옮깁니다.

- [privacy.md](privacy.md): 개인정보 처리방침 공개본
- [terms.md](terms.md): 이용약관 공개본
- [ai-notice.md](ai-notice.md): AI 이용 안내 공개본
- [legal-pages.full.json](legal-pages.full.json): 앱 TS 소스가 아닌 JSON 형태의 공개 고지 원문 전체
- [policies.json](policies.json): 공개 고지 문서의 경로와 변경 기록 위치
- [CHANGELOG.md](CHANGELOG.md): 공개 고지 변경 기록
- [archive/2026-10-13](archive/2026-10-13): 2026-10-13 이전판 원문

서비스의 법적 고지 화면은 이 폴더의 변경 기록과 보존 원문을 기준으로 이전 판을 안내합니다.
