# Canvas-Chat 공개 지원 저장소

이 저장소는 Canvas-Chat 서비스의 공개 문의, 보안 제보 안내, 공개 법적 고지, 공개 가능한 미디어 출처를 모아 두는 **코드 없는 지원 저장소**입니다.

- 서비스: https://canvas-chat-ten.vercel.app
- 공개 문의: https://github.com/Junghwamin/Canvas-Chat-Support/issues
- 보안·개인정보 제보: https://github.com/Junghwamin/Canvas-Chat-Support/security/advisories/new

Canvas-Chat 앱 소스는 비공개 저장소에서 관리합니다. 이 저장소에는 앱 소스 코드, 빌드 산출물, API 키, 운영 비밀, 개인 데이터가 들어가지 않습니다.

## 문의 전에 확인해 주세요

공개 Issues에는 아래 내용을 올리지 마세요.

- OpenAI, Google, Tavily, Brave, Vercel, GitHub 등의 API 키나 토큰
- 개인 문서 원문, 대화 내용, 백업 파일, 브라우저 저장 데이터
- 이름, 연락처, 계정 식별자, 접속 시각처럼 본인이나 타인을 식별할 수 있는 정보
- 아직 공개하면 안 되는 보안 취약점 재현 절차

일반 기능 문의, 버그 제보, 사용법 질문, 상업적 이용 문의는 공개 Issues로 남길 수 있습니다. 보안 취약점이나 개인정보가 필요한 요청은 비공개 보안 제보를 사용하세요.
