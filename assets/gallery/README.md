# 랜딩 갤러리 이미지

이 폴더에는 Canvas-Chat 랜딩 화면에 쓰는 자체 제작 화면 이미지 3장의 공개 사본과 출처 메타데이터를 둡니다. 앱 소스 코드는 포함하지 않습니다.

각 이미지는 예시 데이터를 넣은 Canvas-Chat 앱 화면을 캡처한 뒤 WebP로 인코딩한 것입니다. 세 이미지는 기존 MIT 라이선스를 유지합니다. MIT 원문은 [../../docs/legal/legacy-mit.txt](../../docs/legal/legacy-mit.txt)에 있습니다.

| 파일 | 설명 | MIME | 라이선스 |
| --- | --- | --- | --- |
| [gallery-canvas.webp](gallery-canvas.webp) | Canvas-Chat 캔버스 화면(예시 데이터) | image/webp | MIT |
| [gallery-study.webp](gallery-study.webp) | Canvas-Chat 학습 노트 화면(예시 데이터) | image/webp | MIT |
| [gallery-graph.webp](gallery-graph.webp) | Canvas-Chat 지식 그래프 화면(예시 데이터) | image/webp | MIT |

상세 출처, 지원 저장소 sourceURL, 해시, 크기는 [gallery.json](gallery.json)에 기록합니다.
